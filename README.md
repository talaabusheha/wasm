# وَسم | WASM - دعوات أعراس إلكترونية 💍

موقع Link-in-Bio رسمي وعالي الأداء لعلامة **«وَسم»** لدعوات الأعراس الإلكترونية في فلسطين. الموقع مبني بأحدث التقنيات: **React + Vite + TypeScript + Tailwind CSS** ومُهيأ بالكامل للنشر الفوري على **Netlify**.

---

## 💻 1. تشغيل الموقع محلياً (Run Locally)

1. تأكدي من تثبيت [Node.js](https://nodejs.org/) على جهازك.
2. افتحي موجه الأوامر (Terminal / PowerShell) في مجلد المشروع ونفذي أمر تثبيت الحزم:
   ```bash
   npm install
   ```
3. شغلي السيرفر المحلي:
   ```bash
   npm run dev
   ```
4. افتحي الرابط في المتصفح: `http://localhost:3000`

---

## 🎨 2. كيف تضيفين تصميماً جديداً أو تعدلينه؟ (Manage Designs)

كل تصاميمك تدار من ملف واحد فقط بكل سهولة وبدون تعقيد:
📁 **`src/data/designs.ts`**

### خطوات الإضافة:
1. ضعي صورة غلاف التصميم (يفضل نسبة 9:16 وبصيغة `WebP` لخفة وسرعة التحميل) داخل المجلد:
   `public/designs/`
   مثال: `public/designs/my-design.webp`
2. افتحي ملف `src/data/designs.ts` وأضيفي بيانات التصميم:
   ```typescript
   {
     id: 'emerald',
     name: 'زمردي 💎',
     tag: 'فاخر',
     url: 'https://wasminvites.com/demo/emerald',
     image: '/designs/my-design.webp',
   }
   ```
3. **ملاحظة ذكية:** إذا أردتِ تحضير تصميم دون أن يظهر حالياً للزوار، فقط اتركي الرابط فارغاً `url: ""` وسيقوم الموقع بإخفائه تلقائياً حتى تقومي بإضافة الرابط!

## 🔒 3. لوحة تحكم «موظف وسم» المباشرة (Employee Dashboard)

يمكنك الآن إضافة الكروت وصورها مباشرة من الموقع نفسه وبدون تعديل أي كود:
1. انزلي لأسفل الصفحة (Footer) واضغطي على زر **«🔒 موظف وسم»**.
2. بيانات تسجيل الدخول:
   - **اسم المستخدم:** `wasm`
   - **كلمة المرور:** `2005`
3. ستفتح لكِ نافذة سهلة وسريعة تمكنكِ من:
   - كتابة اسم الكرت.
   - اختيار صورة الكرت مباشرة من موبايلك/جهازك بضغطة زر (أو وضع رابط الصورة).
   - وضع رابط المعاينة وتصنيف الكرت.
   - الضغط على **«حفظ وإضافة الكرت للموقع ✨»** ليظهر فوراً في واجهة الموقع!
   - حذف أي كرت أو استعادة الكروت الأصلية في أي وقت.

## 💬 4. قسم آراء العرايس (Bride Reviews)

تدار لقطات الشاشة لآراء العرايس من الملف:
📁 **`src/data/reviews.ts`**

- ضعي لقطات الشاشة داخل مجلد `public/reviews/`
- أضيفي اسم الصورة ووصفها في الملف:
  ```typescript
  {
    image: '/reviews/bride-1.webp',
    alt: 'رأي عروس بدعوة زفافها',
  }
  ```
- **ملاحظة:** إذا كانت مصفوفة `reviews` فارغة `[]`، فسيختفي قسم "آراء العرايس" تلقائياً من الموقع دون ترك أي فراغ.

---

## 🖼️ 4. الشعار وصورة المشاركة (Logo & Social Share)

- **شعار وسم:** ضعي ملف الشعار بصيغة PNG في المسار:
  `public/logo.png`
  (سيظهر تلقائياً داخل الدائرة بأعلى الصفحة).
- **صورة المشاركة على واتساب وفيسبوك (OG Image):** ضعي الصورة بقياس 1200x630 بكسل في المسار:
  `public/og.jpg`.

## 🚀 5. النشر على Netlify (Deployment)

المشروع يحتوي مسبقاً على ملف `netlify.toml` المهيأ تلقائياً للإنتاج:

### الطريقة الأولى: الربط التلقائي عبر GitHub (موصى بها)
1. ارفعي كود المشروع إلى حسابك على GitHub.
2. سجلي دخولك في [Netlify](https://app.netlify.com).
3. اضغطي على **Add new site** ثم **Import an existing project** واختاري مستودع المشروع.
4. الإعدادات ستكون جاهزة تلقائياً:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. اضغطي **Deploy site**، ثم اربطي دومينك الخاص `wasminvites.com` من قسم **Domain management**.

### الطريقة الثانية: الرفع المباشر اليدوي
1. نفذي أمر بناء المشروع:
   ```bash
   npm run build
   ```
2. سينتج مجلد جديد اسمه `dist/`.
3. ادخلي على Netlify واسحبي مجلد `dist` وأفلتيه في صفحة Sites/Deploys.
